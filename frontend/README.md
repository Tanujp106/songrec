
  # Build out application features

  This is a code bundle for Build out application features. The original project is available at https://www.figma.com/design/y0PUY8r5cRx1aNrci0YMCt/Build-out-application-features.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

  ## API

  This frontend expects the Next.js API to be running at `http://localhost:3000`.
  The Vite dev server proxies `/api/*` requests to that backend.
